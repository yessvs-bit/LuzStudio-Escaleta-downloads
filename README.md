# LuzStudio Escaleta — Descargas

**LuzStudio Escaleta (LSE)** es una aplicación de escritorio para planificar novelas, sagas y otras obras narrativas antes de escribir el manuscrito.

## Qué permite hacer

- Organizar obras independientes y sagas.
- Diseñar capítulos, ordenar escenas y desarrollar tramas.
- Crear plantillas propias con campos configurables para capítulos y tramas.
- Construir cronologías, calendarios ficticios y una línea temporal visual.
- Guardar y clasificar ideas en un Semillero global, con integración con [LuzStudio Ideas](https://github.com/yessvs-bit/LuzStudio-Ideas-downloads).
- Buscar información en todos los proyectos, consultar una guía integrada e imprimir fichas o guardarlas como PDF.
- Crear copias integrales automáticas y manuales para recuperar todos los proyectos y el Semillero en una computadora vacía.

LSE se concentra en la **planificación narrativa**: no incluye un editor de manuscritos. Los proyectos se guardan como archivos normales en la carpeta elegida, por lo que pueden ubicarse dentro de OneDrive u otro servicio de sincronización.

Este repositorio contiene únicamente los instaladores oficiales para Windows. El código fuente y los datos de las obras no se almacenan aquí.
