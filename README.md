# LuzStudio Escaleta — Descargas

Repositorio público destinado únicamente a los instaladores oficiales de **LuzStudio Escaleta para Windows**.

La aplicación organiza obras, escaletas, escenas, ideas, cronologías, calendarios y estaciones. El código fuente y los datos de las obras no se almacenan en este repositorio.

Usá siempre la versión más reciente disponible en la sección **Releases**.
